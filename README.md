# BetTracker

Prywatny tracker kuponów sportowych.

## GitHub Pages
1. Włącz GitHub Pages w Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: main.
4. Folder: /(root).
5. Zapisz ustawienia.

Strona używa localStorage, więc każdy użytkownik ma własne dane zapisane lokalnie w swojej przeglądarce.
